# Implementation Plan

## 前提(全タスク共通)

- **1 タスク = 1 コミット**(requirements.md `D-4`)。各タスクを終えた時点で必ずコミットし、`tasks.md` のチェックボックスと git 履歴を一致させる。
- **途中でテストが赤なのは正常**(`D-1` / `D-4`)。全体が緑になるのは最終段(タスク 8)のみ。各タスクには「このタスク完了時点で緑にできる範囲」を明記しているので、それ以外の赤を障害と誤認しない。
- **`tests/guards/legacy-names.test.ts` は 1.2 で導入し、タスク 7 完了までは必ず赤、タスク 8 完了時点で緑になる**。その失敗一覧を残作業リストとして使う。
- 大分類 1〜8 は design.md 「Migration Strategy」の段 S1〜S8 に 1:1 対応する。段をまたぐ並べ替え・統合をしない。
- 各タスクは単独で実行できるよう、参照すべき design.md の節名を明記している。迷ったら requirements.md の該当 ID と design.md の該当節を先に読むこと。
- 中断する場合は `HANDOVER.md` にブランチ名・到達した段・既知の赤いテストを記録する。
